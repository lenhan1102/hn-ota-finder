# Thư mục chứa Scraper Binary (google-maps-scraper)

Đặt file binary `google-maps-scraper` (hoặc `google-maps-scraper.exe` trên Windows) vào thư mục này:
* **macOS (Apple Silicon / Intel)**: Tải release `darwin-amd64` từ https://github.com/gosom/google-maps-scraper/releases, đổi tên thành `google-maps-scraper` và `chmod +x bin/google-maps-scraper`.
* **Linux**: Tải `linux-amd64` đổi tên thành `google-maps-scraper`.
* **Windows**: Tải `windows-amd64.exe` đổi tên thành `google-maps-scraper.exe`.
